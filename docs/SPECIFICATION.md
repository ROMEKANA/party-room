# アプリの仕様

## 画面とルーム

名前とアイコンを選んで唯一のルームに参加する。入室名とアイコンは端末に保存し、次回アクセス時に復元する。名前をトリムしてNFCへ正規化し、Unicodeコードポイントで数える。新規入室は1〜8文字で制御文字を含まない名前を受け付ける。既存の在籍者と進行中の対戦参加者は旧上限の20文字まで同名復帰できる。同名で別タブや端末から入室すると、ルーム内の位置、ホスト権限、対戦状態を引き継ぎ、以前の接続は終了する。改名やアイコン変更は入室画面で行う。アイコンは固有IDを持つ10種類から選び、絵と背景の組み合わせを固定する。同じアイコンでの入室と対戦を認める。投票、攻撃対象、同期、再接続などの識別には参加者IDを使う。

ロビーでは、ホストが一覧または左右操作でゲームを切り替え、選択ボタンで全員を設定画面へ移動させる。ゲストは共通の選択を見ながら、自分でも一覧を閲覧できる。ロビーのメニューの「ゲームルール」では、ホストとゲストがゲーム一覧から遊び方を選べる。ゲーム中は現在のゲームのルールと設定を閲覧できる。対戦終了後、ホストは再戦、設定への復帰、ロビーへの復帰ができる。

表示・手番・ホスト自動交代は共通のプレイヤー順を参照する。ホストはロビーか開始前に順番をシャッフルでき、ホストの権限は移動しない。tier並び当て・tierお題当ての設定中にお題担当と親を指定していれば、2人をその順に先頭へ置いて残りをシャッフルする。明示退出時は即時交代し、通信切断時は15秒の接続判定に加えて30秒の猶予を設ける。正式退出または45秒間通信がない時点でルームの在籍枠が空く。猶予中は切断表示になり、在籍枠と順番を保持する。観戦者を含めて全員が退出したら、選択ゲーム・対戦・参加順・ホスト・役割指名を消去してロビーに戻る。次の入室者がホストになる。保存済み設定・履歴・お題は保持し、中断した対戦の成績は保存しない。

ルームは観戦者を含めて最大10人。ゲーム選択から開始までは、在籍者の表示順の先頭からゲーム・モードの上限までを参加枠とし、残りは観戦となる。枠が空くと左から順に自動で繰り上がる。ゲーム・モードの選択や既存の並べ替え操作でも、現在の順番と上限で参加枠を判定する。ロビーに戻ると全員が通常のルーム参加者になる。

開始時に参加枠内で接続中の人を対戦参加者として確定する。対戦中の入退室で人数・順番・役割は変わらない。同名で引き継いだ既存の対戦参加者は復帰できる。新しく入室した人は観戦し、公開情報と共通メニューを使える。手札や正解などの非公開情報とゲーム内のプレイヤー操作は対戦参加者に限る。ホストは観戦中も共通管理と既存のホスト用進行操作を使える。対戦終了後は次回の参加枠を再判定し、終了した対戦の名簿・結果・履歴は対戦時の情報を使う。

## 共通UI・操作の設計方針

- スマートフォンやタブレットのホーム画面に追加する際のアプリ名は「いつパ」。ホーム画面とブラウザーのタブでは、ひつじ、スマートフォン、びっくりマーク、定規を描いた黄色背景のアイコンを使用する。サイトの正式名称は「いつでもパーティールーム」。
- スマートフォンの縦画面を最優先にし、プレイ画面はスクロールなしの1画面に収める。上部の共通ヘッダー、中央のゲーム領域、下部の操作領域を基本とし、既存のデザインと操作性をできる限り維持する。
- 入室画面のアイコン選択は5列2行。ゲーム画面上部のプレイヤー列は1〜5人なら1行、6〜10人なら2行で、全ゲーム共通のレイアウトを使用する。
- プレイヤー表示はアイコン、名前、属性、得点の順。複数属性に対応し、0点も得点として表示する。行動済み、手番、投票などの状態マークはアイコンの右下に表示する。同じ行動状態を専用カードに重ねて表示しない。
- 端末と行の利用可能領域に合わせて共通の比率でサイズを調整し、名前や属性は省略せず、狭い列では長い名前を最大2行で表示する。自分・選択中・切断中の強調と、必要な項目だけの描画に対応する。
- ルール・設定・対戦履歴・アップデート情報の閲覧には共通のオーバービューを使う。長い情報は必要な場合にオーバービューの内部でスクロールできるようにする。
- 操作ダイアログを不要に重ねず、再描画などで操作対象が変わらない限り入力中の内容を保持する。カード名などを省略表示する場合は全文を確認できる操作を用意する。
- 長押しが必要な操作では、押下を終了・キャンセルしたら通常表示に戻す。iOSの文字選択や長押しメニューなど、意図しないブラウザ操作は対象コントロールで抑える。

## ゲーム

| ゲームID | 表示名 | 対応人数 |
|---|---|---|
| `tier` | みんなでtier表 | 2〜10人 |
| `circle-cross` | Circle & Cross | 2〜6人 |
| `unknown-battle` | 名前の知らないあのゲーム | 2〜10人。モードにより制限あり |
| `job-battle` | 真・名前の知らないあのゲーム | 2〜10人。チーム戦は4・6・8・10人 |

Tier表は「みんなでtier表」「tier並び当て」「tierお題当て」「全員一致モード」を提供する。手番と役割にはアイコンの表示順を使い、最後尾の右隣は先頭とする。みんなでtier表と全員一致モードは、従来どおりお題担当のランダムな一巡または指名を使う。tier並び当てとtierお題当ては、お題担当を先に決めて右隣を親にする。ランダム設定で前回の親が参加していれば、前回の親がお題担当となる。親を右隣以外の人に手動変更すると、お題担当と親を先頭に置き、残りの順序を保つ。設定画面は基本設定とモード設定の2列で、抽選などの詳細は設定ダイアログから確認できる。難易度・枚数などは共通、各モード固有の設定は別項目として保存される。親・担当者の指名は対戦開始時に消費する。

### Tier表の開始条件と各モード

開始するには接続中の対戦参加者が2人以上必要。入力担当者の人数と1人あたりの枚数（1〜10枚）の積がTier数以上であることを確認する。tier並び当て・tierお題当ての親は入力人数から除く。難易度は簡単（A〜C）、普通（S〜D）、難しい（SS〜E）。「完全ランダム」「できるだけ均等」「真ん中多め」のいずれでも、配布時に全Tierに1枚以上を割り当てる。難しい設定のみんなでtier表では、SSとEが隣のTier（SとD）より先に出ないように設定できる。

お題担当は内蔵のお題を採用・再抽選するか、自由入力できる。内蔵のお題は `server/topics.js` で管理する。カード名は全4モード共通で、NFKC正規化と前後の空白除去後に同じ名前を同一対戦内で受け付けない。

| モード | 進行と設定 |
|---|---|
| みんなでtier表 | 記入者以外が配置を提案し、Good／Badで投票する。Badが投票対象者の半数以上に達すると即時に棄却し、棄却されない場合は全員の投票後に正誤を判定する。誤答時はライフを1消費し、設定に従い正解公開または同じカードで再挑戦する。ライフ0で失敗、残して全カードを判定すればクリア。得点ONでは正答時に記入者へGood数、Goodを投じた人へ1点を加算し、得点は最終結果で公開する。ライフは1〜30で初期値3。得点と記入者への手番開始確認は初期設定OFF。 |
| tier並び当て | 親以外が入力し、親がすべてのカードを配置する。全Tierを使用して提出する。正答率モード（既定70%、3回）では設定した正答率以上、完全モードでは全問正解でクリア。提出上限は1〜10回で、正答率は10%刻みで設定できる。記入者表示は初期設定OFF。入力中のTier表確認が有効な場合、割当済みTierのプレビューを見られるのは親以外の対戦参加者。 |
| tierお題当て | 親以外が入力したカードは指定Tierに自動配置される。親が口頭でお題を当て、お題担当が判定する。担当が切断中は接続中の親以外の参加者が判定を引き継ぐ。ライフは1。親と観戦者へのお題公開は結果画面で行う。親への記入者表示は初期設定OFF。 |
| 全員一致モード | 入力中に見られる自分のカードは全員が入力を完了するまで編集できる。配置開始時のカード順は全員共通で、自分のTier表を独立して作る。配置中の投稿者表示は初期設定OFF。全カードを配置し全Tierを使用して確定する。確定済みのTier表は自分だけ確認でき、全員確定後は各人の配置・投稿者・指定Tierと不一致カードを表示する。全カードのTierが全員で一致すればクリア。 |

### Circle & Cross

○3枚と×1枚で開始する。初回の親はランダムで、札を伏せる順番は共通順を参照する。全員が1枚ずつ伏せた後は、さらに伏せるか競りを開始する。宣言は現在より大きく、場の伏せ札の合計枚数以下とする。他の全員がパスすると挑戦者が確定する。挑戦者は自分の山を先に公開し、各山の上からめくる。宣言した枚数の○を公開すると1勝、×をめくると失敗して本人が札を1枚失う。札が尽きると脱落し、2勝または最後の1人で決着する。自分の手札だけを閲覧でき、他の人には枚数と公開済みの札が見える。固定ルールのため、設定画面には人数、初期手札、勝利条件を表示する。

### 名前の知らないあのゲーム

全員が同じターンで行動を選択し、サーバーで確定する。バトルロイヤルは2〜10人、チーム戦は4・6・8・10人、ボス戦は4人。最後の生存者または生存チームが勝利し、双方が同時に全滅すれば引き分け。ボス戦の参加枠は共通順の先頭4人。

| 設定 | 既定 | 選択肢 |
|---|---:|---|
| 初期HP | 3 | 1〜5 |
| エネルギー上限 | 3 | 1〜5 |
| ターンごとの被弾上限 | 1 | 1〜5・なし |
| 連続防御制限 | 3回 | 1〜5回・なし |
| 行動制限時間 | 10秒 | 1・3・5・10・15・20・30・45・60秒・なし |
| ターン開始前の通信猶予 | 1,000ms | 500〜3,000ms、250ms刻み |
| ターン終了時の通信猶予 | 800ms | 400〜2,000ms、200ms刻み |
| ターン結果表示時間 | 1,500ms | 750〜3,000ms、250ms刻み |

右側のモード設定では、チーム戦の参加者を共通順の前半・後半でピンクと水色に分ける。ホストは異なるチームの2人をタップして交換するか、サーバーで均等にランダム分けできる。手動の編成は共通順のシャッフル後も維持する。ボスは開始時にランダムで決めるか、参加枠の人を指名する。通信猶予と結果表示時間は設定オーバービューの「詳細」に置く。

| 行動 | 消費 | 効果 |
|---|---:|---|
| 溜める | 0 | エネルギー＋1。ボスは＋2 |
| ガード | 0 | 自分への攻撃をすべて防ぐ |
| 単体攻撃 | 1 | 敵1人に1ダメージ |
| 全体攻撃 | 3 | 生存中の各敵に1ダメージ |
| かばう | 0 | 生存中の味方1人への攻撃をすべて防ぐ |
| 渡す | 1 | 生存中の味方1人のエネルギー＋1 |

初期エネルギーは0。ボスの初期HPは共通設定の2倍で、上限エネルギーは共通。チーム戦とボス戦の3人側はサポート行動を使え、ボス戦の3人側には全体攻撃がない。ガードとかばうは連続回数を共用し、他の行動で回数がリセットされる。攻撃は互いに攻撃し合う組み合わせだけ相殺する。敵対する全体攻撃同士が出た場合は全員の攻撃が無効。相殺・防御されても攻撃のコストは消費する。かばうは対象への攻撃を直接防ぎ、相互のかばうや複数人のかばうも同時に適用される。複数の被弾を合算してから上限を適用する。渡されたエネルギーは行動の判定後に加算し、超過分は消える。そのターンに脱落する人も行動を実行する。

選択中は他人には提出の有無だけが見える。ガードなど対象のない行動はタップで提出し、単体攻撃などは対象カードのタップ時に提出する。未提出は溜める。時間制限なしの正式退出者も、提出済みの行動がなければ溜める。既存の同名再入室で受付済み行動と対戦状態を復元する。対戦中は参加者・チーム・カード位置を固定し、観戦者は公開済みの行動と結果を確認できる。履歴には設定、編成、勝敗、経過ターン、各プレイヤーの最終状態と最後のターンの行動を保存する。

### 真・名前の知らないあのゲーム

同時ターン制のバトルロイヤルとチーム戦で遊ぶ。チーム分け、開始人数、勝敗、基本行動は「名前の知らないあのゲーム」と共通。基本初期HP・最大HPは3、エネルギーの上限は3。被弾上限、連続防御制限、行動制限時間、通信猶予と結果表示時間はこのゲーム用に個別保存する。

開始するとサーバーが全10職業から各人に重複しない3候補を配る。候補と選択内容は本人だけが確認でき、観戦者には確定済み人数を表示する。他のプレイヤーと同じ職業も使える。全員が確定すると、職業を同時公開して第1ターンへ進む。再接続で候補と確定済みの職業を引き継ぎ、再戦ごとに抽選する。途中で離脱した参加者の未確定分は同名復帰まで待つ。対戦履歴の詳細には各人の職業を保存する。

| 職業 | HP補正 | 能力 |
|---|---:|---|
| 戦士 | 0 | 単体・全体攻撃のダメージが2倍。消費と相殺の扱いは共通。 |
| 重戦士 | ＋2 | 初期HP・最大HPが5になる。 |
| 僧侶 | 0 | 回復（消費1）。自分、またはチーム戦なら生存中の味方のHPを1回復する。最大HPを超えず、脱落中のプレイヤーは対象外。 |
| 剣士 | －1 | 反撃（消費1）。相殺やかばうで防がれず届いた単体攻撃を無効にし、各攻撃者に1ダメージ。全体攻撃には無効。攻撃されなくても消費し、連続防御制限をガード・かばうと共有する。 |
| 魔法使い | 0 | 全体攻撃の消費が3から2になる。 |
| 武闘家 | 0 | 溜めるとエネルギー＋2。 |
| 暗殺者 | 0 | 貫通攻撃（消費2）。敵1人に1ダメージ。通常のガードを通過し、かばう・相殺・反撃を受ける。 |
| 騎士 | 0 | ガードで1件以上防いだターンにエネルギー＋1。 |
| 盗賊 | 0 | 単体攻撃が防御・相殺・反撃で無効にならずに命中すると、敵の消費後に残ったエネルギーを1奪う。上限までの空きがある場合に移す。 |
| 呪術師 | 0 | 呪い（消費1）。敵1人の次のターンだけ通常ガードを禁止する。ダメージなし。反撃などは選択可能。 |

被弾上限は有効な攻撃・反撃の件数で判定する。ダメージが大きい順に上限まで採用する。同じダメージなら攻撃者IDの昇順を使う。上限1件のとき、戦士からの攻撃が採用されれば2ダメージになる。

### ナンバークラッシュ

2〜6人の個人戦。手札は全員同じ数字の構成で、初期得点は0点。手札の枚数と総ターン数は等しい。得点カードの山札はサーバーでシャッフルし、毎ターン1枚を公開する。

| 手札枚数 | 手札 | マイナスの得点カード | プラスの得点カード |
|---|---|---|---|
| 9枚（既定） | 1〜9 | −3〜−1 | ＋1〜＋6 |
| 12枚 | 1〜12 | −4〜−1 | ＋1〜＋8 |
| 15枚 | 1〜15 | −5〜−1 | ＋1〜＋10 |

- 全員がタップでカードを選ぶ。全員が提出した時点で選択を固定する。制限時間到達時は通信猶予で送信中の提出を受け付け、最終締切で未選択者の残り手札から最小値を出す。出したカードは消費する。制限時間なしで正式退出した人も、全員の提出を判定する際は未提出なら自動選択の対象にする。
- 数字が重複した人は全員が得点の対象外になり、各人につき1回、0〜3点（既定1点）のペナルティを適用する。累計は負の値も取る。
- 場の合計が0以上なら最大値、負なら最小値を使う。持ち越しON（既定）では全員の中の対象値が重複すると、次点には配分せず場のカードを繰り越す。OFFでは重複を除いた中で判定し、全員無効なら持ち越す。次ターンは持ち越し分と新規公開分を合算する。最終ターンで獲得者が決まらない場は破棄する。
- 選択制限時間と通信猶予の選択肢・既定値は「名前の知らないあのゲーム」と共通。詳細設定では、カード公開表示時間（既定1,000ms）と得点判定表示時間（既定2,000ms）を個別に変更できる。どちらも750〜3,000msの250ms刻み。
- 共通のプレイヤー列で名前の下に得点、アイコンの右下に選択済みのチェックを表示する。画面上部に場を固定し、下部では3列の手札、同時公開、得点判定を切り替える。長押し中は下部に得点カードを昇順に並べ、公開済みを暗く表示する。得点は判定フェーズでまとめて反映する。
- 最終ランキングは得点の降順で同点は同順位。たとえば1位が2人なら次は3位。履歴にはゲームID、日時、参加者、手札枚数、重複ペナルティ、持ち越し設定、最終順位と点数を保存する。

## 履歴と更新

履歴は最後まで遊んだ対戦結果を新しい順に表示する。ロビーでは全ゲーム、ゲーム内では現在選んでいるゲームを対象とする。ホストによる履歴リセットも同じ範囲に適用する。ゲームとロビーを切り替えても、開いているルール・対戦履歴・アップデート情報の表示を保つ。対戦履歴は開いた時点の範囲で一覧と詳細を閲覧できる。履歴保存期間は30分・1時間・2時間・3時間・5時間・1日から共通設定で選び、初期値は2時間。期間変更は既存の履歴にも適用する。

公開版が新しくなった場合、名前入力・ロビー・設定・最終結果画面では更新を案内する。対戦中は画面を止めず、終了後に案内する。更新前に入室していた場合は保存済みの名前で自動再入室する。更新後も旧版が読み込まれた場合は更新操作を再度案内し、再入室に失敗した場合は名前入力画面から参加し直せる。初回表示・タブ復帰・低頻度の確認で公開版を取得する。

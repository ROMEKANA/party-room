# 公開とアップデート情報

| 変更内容 | 更新する番号 | 例 |
|---|---|---|
| ゲーム追加 | 第1番号 | 2.x.x → 3.0.0 |
| 既存ゲームのモード追加 | 第2番号 | 2.0.0 → 2.1.0 |
| その他の変更・修正・お題追加 | 第3番号 | 2.1.0 → 2.1.1 |

複数の変更があれば最も大きい番号を更新する。全画面・状態同期API・公開版確認のバージョンは `web/version.js` に集約する。

`web/release-data.js` にアップデート情報を追加する。変更ごとに `gameIds` を指定する。空配列は共通システムを表し、名前入力画面とロビーに表示する。1つの変更に複数のIDを登録でき、ゲーム内は自分のゲームIDを含む変更だけを表示する。過去の正式リリースは履歴として保持する。

`npm test` と複数クライアントによる動作確認の後、既存プロジェクトに公開する。データの互換性と、進行中の旧クライアントでの操作を確認する。非互換変更は本番ルームがプレイ中でない時間帯に公開する。必要なら直前のデプロイ済みバージョンを再デプロイできる。

公開物はビルド済みWorkerとその配信アセット。ドキュメントはリポジトリに保存し、Webから直接配信しない。
